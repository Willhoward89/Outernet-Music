# 842 Broadway

An annotated, sourced text on **842 Broadway / One Union Square South** (1998) and the block that
stood there before it — Wallack's Theatre, the Union Square Theatre, the Morton House, the Rogers
Peet Building — traced through a century of atlases and land books.

Every quoted passage is highlighted and colour-coded by source. Where the source page is on file,
clicking a highlight opens that scanned page in a panel beside the text.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole document — **self-contained**. Every photograph, source scan and the audio track are embedded in the file itself, so there are no asset folders and nothing else to upload. 18.7 MB. |
| `842-broadway-highlighted-sourced.pdf` | Print/offline version, 56 pages, scans included as an appendix. |

## The document

Three columns on a wide screen:

- **Left** — six photographs of the building today; click any one to enlarge.
- **Centre** — the text. 103 highlighted quotes, colour-coded by source; 87 open their source page.
- **Right** — the citation chart. Click a number to jump to that quote; click *scan* to open the page.

Both side columns are sticky. The audio player (26 min 02 s) sits above the text.

## Sources

24 works are cited; the colour key lists them all. Six cited pages have no scan yet, so 16 of the
103 quotes are cited but not clickable: Stern, *New York 1880*, p. 665 (9 quotes); Miller,
*Greenwich Village and how it got that way*, p. 110 (2); Stokes, *Iconography* Vol. Five, p. 1825
(2); Stokes, *Iconography* Vol. Three, p. 986 (1); Howe, *New York Shopping Guide for 1895*, p. 33
(1); *Oasis Map*, p. 1 (1).

The embedded page scans are reproductions of copyrighted book pages, included as citation evidence.
If this repository is public, they are published to the open web.
