# 881–887 Broadway — The Palimpsest of a Metropolitan Corner

881–887 Broadway / 113–115 Fifth Avenue / 9–13 East 18th Street: the Arnold Constable store and the
corner it has held since 1869.

**All 82 quotes are sourced; 81 of them are clickable** and open their scanned page.

**Repository path:** `brick-cakes/881-887-broadway/`

## How it reads

**The citation chart is on the left; the photographs are on the right.**

- **Left — the citation chart.** It follows you as you scroll, and jumps to the matching entry when
  you hover a highlight. Click a number to go to that quote, or *scan* to open the page.
- **Centre — the text.** 82 highlighted quotes, colour-coded by source.
- **Right — the views.** Six photographs under *Views of the corner*; click any to enlarge.

The side columns are sticky and stack above the text below ~1360px.

Notes for the record:

- **One page is still without a scan** — Murphy, *Murph Guide Closed Bars*, 2023, p. 15, one quote
  (*America.*). It is sourced and colour-coded; drop the page into `assets/scans/` under that exact
  name and rebuild to reach 82 of 82.
- **White & Willensky, *AIA Edition 1*, 1968, p. 94 is now on file**, which closed quote 31 —
  *"Constable probably felt limestone and brick to be more imposing architecturally than the then
  currently popular cast iron. Note the steep two-storied mansarded roof."* It came as one opening
  of the book with p. 95, which finished 889 Broadway.
- **The scans are not marked on this document.** Quote-boxing — where a highlight opens its page
  with the quoted lines boxed — was added to the series after this one was built. It can be run
  here on request; it needs an OCR pass over the 34 scans.

To replace or add a scan, drop it into `assets/scans/` named exactly as the citation reads and
rebuild.

## Publishing

GitHub displays `.html` as source code. The rendered page is at:

```
https://willhoward89.github.io/Outernet-Music/brick-cakes/881-887-broadway/
```

Pages is already enabled on this repository, so it appears a minute or two after the push.

To check it locally:

```bash
cd 881-887-broadway && python3 -m http.server 8000
# open http://localhost:8000
```

## A note on the scans

The page scans are reproductions of copyrighted book pages, included as citation evidence for the
quoted passages. If this repository is public, they are published to the open web.
